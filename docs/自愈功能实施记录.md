  - 新：每 4 小时运行一次（04:00, 08:00, 12:00, 16:00, 20:00, 23:50 UTC）

- **预期效果**：
  - 数据漂移检测窗口从 24 小时缩短到 4 小时
  - 孤儿单、余额漂移、持仓丢失等问题更快被发现

### 3. P1 优化：余额主动同步 ✓
- **修改文件**：`main.py:440-456`
- **新增任务**：`hourly_balance_sync`
- **执行逻辑**：
  1. 查询账户当前持仓
  2. 如果无持仓，调用 `_sync_balance_before_place` 同步余额
  3. 如果有持仓或查询失败，跳过（避免干扰活仓）
- **触发时机**：每小时 05 分
- **预期效果**：
  - 充值/提现后 1 小时内自动同步到 db
  - 不再需要等到下次挂单或重启

## 监控指标

### 关注日志
- `[daily-heal]`：深度对账日志，关注余额差异
- `[hourly-balance-sync]`：余额同步日志，关注充值/提现
- `[reconcile] [protect]`：保护检查日志，关注孤儿单

### 异常阈值
- 余额漂移 >1%：需排查是否有未记录的充值/提现
- 孤儿单数量 >0：需排查 algo 单状态同步问题
- 对账失败率 >1%：需排查网络或 OKX API 稳定性
