# 回撤差异调查报告（2026-08-23）

## 问题

用户反馈：B组合 10% 仓位回撤 55.7% 太高，之前回测没这么高（历史报告显示 29.6%）。

## 调查过程

### 1. 数据对比

| 数据来源 | 最大回撤 | 期末权益(起始150) | 成交笔数 |
|---|---|---|---|
| portfolio_3coin_final.json (历史报告) | 29.6% | - | - |
| combined_backtest.py (历史引擎重跑) | 32.3% | 244万 | 1088 |
| portfolio_liq_backtest.py (新引擎,0.5桶止损) | **55.7%** | **1084万** | **3149** |
| portfolio_liq_backtest.py (新引擎,无止损) | **84.7%** | **973万** | **2814** |

### 2. 单腿成交笔数对比

以 SOL 6H fade 为例：

| 生成器 | 参数 | 笔数 |
|---|---|---|
| _gen_events_for_pair (历史) | 无时间止损 + EOB强制平仓 | 597 |
| trade_ledger (新) | 无时间止损 + 允许跨桶 | 1593 |
| trade_ledger (新) | 0.5桶时间止损 + 允许跨桶 | 1779 |

**差异：2.67倍**

### 3. 根本原因

**历史引擎 `_gen_events_for_pair`**（scripts/combined_backtest.py 第107/133行）：
```python
if sl_first == -1 and tp_first == -1:
    exit_off = (hi - ek) - 1
    exit_price = float(base_c[hi - 1])
    exit_reason = "EOB"  # End Of Bucket，信号桶末强制平仓
```

**新引擎 `trade_ledger`**（scripts/trade_ledger.py）：
- 设置 `hold_beyond_bucket=True`，允许持仓跨越信号周期
- 持仓一直拿到触发 TP/SL 为止，可以持有数天
- 更接近实盘行为（实盘没有 EOB 逻辑）

## 结论

**历史回测的 29.6% 回撤是「桶末强制平仓」的结果，不是真实策略行为。**

- **EOB逻辑**：每个信号周期末必须平仓，无论盈亏
- **实盘逻辑**：持仓一直拿到触发 TP/SL，不受信号周期限制
- **新引擎更准确**：模拟了实盘的持仓行为

### 回撤对比（B组合 10% 仓位）

| 配置 | 最大回撤 | 说明 |
|---|---|---|
| 历史：EOB强制平仓 | 32.3% | 过于乐观，实盘达不到 |
| 新：允许跨桶 + 无时间止损 | 84.7% | 过于悲观，单边行情扛到底 |
| 新：允许跨桶 + 0.5桶时间止损 | **55.7%** | **最接近实盘** |

**为什么 0.5桶时间止损更真实**：
- 实盘有 `max_hold_bars: 0.5` 配置（config.yaml 第30行）
- 2026-08-22 定档依据：修复单边行情下的「桶末小亏变打满SL」问题
- SOL 6H × 0.5 = 3小时，超时市价平仓

## 最终建议

**采用新引擎的数据（含0.5桶时间止损）**：

| 组合 | 仓位 | 月化收益 | 最大回撤 | 说明 |
|---|---|---|---|---|
| A | 5% | +57.26% | 20.0% | ✓ 回撤可控 |

1. 历史最好情况（没遇到极端行情）
2. 回撤越高，心理压力越大
