# 版本与 exe 更新指南

## 版本号

- 唯一来源 `version.py` (`__version__ = "主.功能.修复"`)
- 出现在: GUI 窗口标题 / `hlbot-cli --help` 首行 / 启动日志 `[boot] HighLow Bot vX.Y.Z`
- 发版三步: 改 `version.py` → `build.bat` → `git tag v<版本>` (代码与产物可回溯对应)

## 构建

```powershell
build.bat
# = pytest 全绿 → pyinstaller → --help 冒烟 → 泄密断言 → dist\hlbot-v<版本>\
```

产物 `dist\hlbot-v<版本>\`:

| 文件 | 说明 |
|---|---|
| `hlbot.exe` | GUI 窗口版 (监控/配置编辑/启停控制/日志) |
| `hlbot-cli.exe` | 终端版: 无参数=rich 面板; 子命令=运维工具 |
| `_internal\` | 依赖运行时 (两个 exe 共享) |

## 首次部署

1. 整个 `hlbot-v<版本>` 文件夹拷到部署机**可写目录** (不要 Program Files)
2. 双击运行 → 自动生成 `config.yaml` 模板并退出
3. 填 API key、启用账户 (`enabled: true`)、按需配 proxy → 再次运行
4. 用户数据全在 exe 旁, 与程序分离:

```
hlbot-v1.0.0\
  hlbot.exe / hlbot-cli.exe / _internal\   ← 程序 (更新时替换)
  config.yaml / .env                        ← 配置 (更新时保留)
  data\trades.db                            ← 交易记录 (更新时保留)
  logs\                                     ← 日志 (更新时保留)
  docs\daily_reports\                       ← 日报 (更新时保留)
```

## 更新到新版本

1. **停止**机器人 (GUI 停止按钮 / 终端 Ctrl+C; 挂单持仓在 OKX 侧继续有效)
2. 删除旧 `hlbot.exe`、`hlbot-cli.exe`、`_internal\` 三样, 拷入新版的这三样
   (config.yaml/.env/data/logs 一概不动)
3. 启动 → catchup 自动补当前桶, reconciler 自动对账, 无需人工干预

## 配置兼容规则 (代码内建, 升级无需迁移脚本)

- **新增配置项**: 默认值 = 旧行为, 旧 config.yaml 直接可跑, 想用新参数再加
- **拼错/已删除的键**: 启动时 `validate_config` 明文提示, 不会静默吞掉
- **db schema 变更**: `data/db.py::_init_schema` 内 `ALTER TABLE ADD COLUMN` 自动迁移
  (先例: trigger_price 列), 旧 db 直接兼容
- **降级**: 换回旧版本文件夹即可; 若新版本加过 db 列, 旧代码不识别但不冲突 (SQLite 宽松读)

## 版本规划

| 版本 | 内容 |
|---|---|
| v1.0.0 | 首版 exe: GUI + CLI 子命令 + 全参数配置化 |
| v1.x | 功能增补 (如 GUI 内更新检查、更多配置项), config 向后兼容 |
| v2.0 | 破坏性变更时才用 (config 结构不兼容、db 大改), 升级说明随版发布 |

## 回测/研究脚本

`bucket_backtest / strategy_lab / walk_forward` 等 pandas 系脚本**不打包**,
仍在源码环境 `python scripts/xxx.py` 跑 (部署机不需要)。
